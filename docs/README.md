# Project Documents

This folder contains report, proposal, and demo artifacts for the public project repository.

| File / Folder | Purpose |
|---|---|
| `final_report.pdf` | Final project report. |
| `project_proposal.pdf` | Original proposal. |
| `demo/` | Placeholder location for final demo video or GIF. |
| `screenshots/` | Architecture image and future polished UI screenshots. |
| `archive/` | Older planning materials retained for project history. |

The current report can be opened directly from `docs/final_report.pdf`. To view the interactive demo, run the Streamlit app from `FinSight_RAG/` and open the local URL printed in the terminal.
